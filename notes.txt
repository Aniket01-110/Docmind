PRODUCT VISION:
A full-stack AI product where users can:
- Upload ANY file type (PDF, audio, image, CSV)
- Ask questions — get AI answers from documents
- Search the web when document doesn't have answer
- System automatically decides best retrieval strategy
- Self-corrects if retrieval quality is poor
- Per-user login, document management, chat history
- Export conversations as PDF
- Confidence scores + source citations

================================================================
ARCHITECTURE TYPE:
Multimodal + Corrective + Adaptive RAG
================================================================

WHAT MAKES IT ADVANCED:
→ Multimodal: handles PDF, audio, image, CSV
→ Adaptive: classifies query complexity
           dynamically selects strategy
→ Corrective: evaluates retrieval quality
              self-corrects poor retrieval
              web search fallback
→ Self-Reflecting: checks answer completeness
                   iterates if incomplete
→ Web Retrieval: searches internet for
                 queries beyond document scope
→ Hybrid Search: BM25 + semantic for better retrieval
→ Reranking: cross-encoder for accurate results
→ Citations: document + web sources cited
→ Confidence: scores on every answer
